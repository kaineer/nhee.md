Погода и небо

天
てん, あま
Небо, небеса
  • 天気 = てんき (Погода)
  • 天国 = てんごく (Рай)
  • 天の川 = あまのがわ (Млечный Путь (Небесная река))
空
そら, くう
Небо
  • 空気 = くうき (Воздух)
  • 青空 = あおぞら (Голубое небо)
  • 空港 = くうこう (Аэропорт)
雨
あめ, う
Дождь
  • 大雨 = おおあめ (Ливень, сильный дождь)
  • 雨具 = あめぐ (Дождевик, плащ от дождя)
  • 梅雨 = つゆ (Сезон дождей)
風
かぜ, ふう
Ветер
  • 台風 = たいふう (Тайфун)
  • 風邪 = かぜ (Простуда)
  • 風景 = ふうけい (Пейзаж, вид)
雪
ゆき, せつ
Снег
  • 大雪 = おおゆき (Сильный снегопад)
  • 雪だるま = ゆきだるま (Снеговик)
  • 雪国 = ゆきぐに (Снежная страна)
晴
はれ, せい
Ясная погода
  • 晴れ = はれ (Ясно, солнечно (прогноз погоды))
  • 晴天 = せいてん (Ясное небо)
  • 晴れる = はれる (Проясняться, становиться солнечно)
曇
くも, どん
Пасмурно, облачно
  • 曇り = くもり (Облачно (прогноз погоды))
  • 曇天 = どんてん (Пасмурное небо)
  • 曇る = くもる (Затягиваться облаками, становиться пасмурным)
星
ほし, せい
Звезда
  • 星占い = ほしうらない (Астрология, гороскоп)
  • 流星 = りゅうせい (Метеор, падающая звезда)
  • 星空 = ほしぞら (Звездное небо)
太
たい, ふと
Большой, толстый
  • 太陽 = たいよう (Солнце)
  • 太い = ふとい (Толстый (о предмете))
  • 太る = ふとる (Толстеть, набирать вес)
光
ひかり, こう
Свет
  • 日光 = にっこう (Солнечный свет)
  • 光る = ひかる (Светиться, сиять)
  • 光線 = こうせん (Луч света)
