Люди

人
ひと, じん, にん
Человек
  • 日本人 = にほんじん (Японец)
  • 一人 = ひとり (Один человек)
  • 人気 = にんき (Популярность)
男
おとこ, だん
Мужчина
  • 男の人 = おとこのひと (Мужчина)
  • 男子 = だんし (Мальчик, юноша, мужчина)
  • 男性 = だんせい (Мужской пол, мужчина)
女
おんな, じょ
Женщина
  • 女の人 = おんなのひと (Женщина)
  • 女子 = じょし (Девочка, девушка, женщина)
  • 女性 = じょせい (Женский пол, женщина)
子
こ, し
Ребенок
  • 子供 = こども (Ребенок, дети)
  • 息子 = むすこ (Сын)
  • 女子 = じょし (Девочка, девушка)
友
とも, ゆう
Друг
  • 友達 = ともだち (Друг, товарищ)
  • 友人 = ゆうじん (Друг)
  • 親友 = しんゆう (Близкий друг, лучший друг)
先生
せんせい
Учитель, наставник
  • 先生 = せんせい (Учитель, преподаватель)
  • 医者 = いしゃ (Врач)
  • 学校の先生 = がっこうのせんせい (Школьный учитель)
学
がく, まな
Учеба, изучение
  • 学生 = がくせい (Студент, учащийся)
  • 学校 = がっこう (Школа)
  • 学習 = がくしゅう (Обучение, изучение)
校
こう
Школа
  • 学校 = がっこう (Школа)
  • 高校 = こうこう (Старшая школа)
  • 小学校 = しょうがっこう (Начальная школа)
父
ちち, ふ
Отец
  • お父さん = おとうさん (Папа)
  • 父 = ちち (Мой отец)
  • 父母 = ふぼ (Отец и мать, родители)
母
はは, ぼ
Мать
  • お母さん = おかあさん (Мама)
  • 母 = はは (Моя мать)
  • 母国 = ぼこく (Родина)
