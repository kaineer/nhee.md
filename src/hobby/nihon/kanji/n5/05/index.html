Время

日
にち, ひ, か
Солнце, день
  • 日曜日 = にちようび (Воскресенье (день Солнца))
  • 今日 = きょう (Сегодня)
  • 三日 = みっか (Третье число месяца (или три дня))
月
つき, げつ, がつ
Луна, месяц
  • 月曜日 = げつようび (Понедельник (день Луны))
  • 一月 = いちがつ (Январь (первый месяц))
  • 半月 = はんげつ (Полмесяца, полулуние)
年
ねん, とし
Год
  • 今年 = ことし (Этот год (текущий))
  • 去年 = きょねん (Прошлый год)
  • 年上 = としうえ (Старший по возрасту)
時
じ, とき
Время, час
  • 時間 = じかん (Время (промежуток), часы)
  • 三時 = さんじ (Три часа (время))
  • 時々 = ときどき (Иногда, время от времени)
分
ふん, ぶん
Минута, часть
  • 五分 = ごふん (Пять минут)
  • 三十分 = さんじゅっぷん (Тридцать минут (полчаса))
  • 半分 = はんぶん (Половина)
週
しゅう
Неделя
  • 今週 = こんしゅう (Эта неделя)
  • 来週 = らいしゅう (Следующая неделя)
  • 先週 = せんしゅう (Прошлая неделя)
朝
あさ, ちょう
Утро
  • 朝ご飯 = あさごはん (Завтрак)
  • 朝日 = あさひ (Утреннее солнце (восход))
  • 朝方 = あさがた (Под утро, ранним утром)
昼
ひる, ちゅう
Полдень, день (светлое время)
  • 昼ご飯 = ひるごはん (Обед)
  • 昼間 = ひるま (Днём, в светлое время суток)
  • 昼休み = ひるやすみ (Обеденный перерыв)
夜
よる, や
Ночь
  • 夜ご飯 = よるごはん (Ужин)
  • 今夜 = こんや (Сегодня вечером, этой ночью)
  • 夜中 = よなか (Глубокой ночью, полночь)
今
いま, こん
Сейчас, настоящее время
  • 今日 = きょう (Сегодня)
  • 今度 = こんど (На этот раз, в следующий раз)
  • 今まで = いままで (До сих пор, до настоящего времени)
