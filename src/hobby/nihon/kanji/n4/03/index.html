Прилагательные, 2

特
とく, とっ
Особенный, специальный
  • 特に = とくに (Особенно)
  • 特別 = とくべつ (Особенный, специальный)
  • 特急 = とっきゅう (Экспресс (скорый поезд))
別
べつ, わか
Отдельный, раздельный
  • 別れます = わかれます (Расставаться, отделяться)
  • 別々に = べつべつに (Отдельно, порознь)
  • 区別します = くべつします (Различать, отличать)
  • 分別します = ぶんべつします (Классифицировать, разделять)
  • 送別 = そうべつ (Прощание, проводы)
有
あ, ゆう
Наличие, существование
  • 有ります = あります (Иметь, быть, находиться)
  • 有名 = ゆうめい (Известный, знаменитый)
  • 有料 = ゆうりょう (Платный)
便
べん, びん
Удобство, почта
  • 便り = たより (Письмо, весточка)
  • 便利 = べんり (Удобный)
  • 郵便局 = ゆうびんきょく (Почтовое отделение)
  • 船便 = ふなびん (Морская почта)
利
り
Прибыль, выгода
  • 便利 = べんり (Удобный)
  • 利用します = りようします (Использовать, пользоваться)
  • 利し = りし (Процент, прибыль)
  • 有利 = ゆうり (Выгодный, преимущественный)
不
ふ, ぶ
Не, отрицание (префикс)
  • 不便 = ふべん (Неудобный)
  • 不足します = ふそくします (Не хватать, быть недостаточным)
  • 不安 = ふあん (Беспокойство, тревога)
  • 不運 = ふうん (Неудача, несчастье)
切
き, せつ
Резать, отрезать
  • 切ります = きります (Резать, отрезать)
  • 切手 = きって (Почтовая марка)
  • 大切 = たいせつ (Важный, ценный)
  • 親切 = しんせつ (Добрый, любезный)
元
げん, がん, もと
Происхождение, источник, начало
  • 元気 = げんき (Здоровый, бодрый)
  • 元日 = がんじつ (Новый год (первый день года))
  • 地元 = じもと (Местный, родной город)
好
す, こう
Любить, нравиться
  • 好き = すき (Нравиться, любить)
  • 大好き = だいすき (Очень нравится, обожать)
  • 好意 = こうい (Расположение, симпатия)
  • 好物 = こうぶつ (Любимое блюдо)
急
いそ, きゅう
Спешить, срочный
  • 急ぎます = いそぎます (Спешить, торопиться)
  • 急に = きゅうに (Внезапно, неожиданно)
  • 特急 = とっきゅう (Экспресс (скоростной поезд))
  • 急用 = きゅうよう (Срочное дело)
